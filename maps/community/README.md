# 已收集的英雄无敌 III 地图

0.46 当前共 **15 张原始下载地图、29 层地形预览**。新增官方《死人和被埋葬的人 / Dead and Buried》，来自 [HeroesWorld 标准地图合集](https://heroesworld.net/topic/8850/list-of-standard-maps-for-heroes-3/)。该图原文件为 RoE 格式，保留不变并经过地形与对象身份核对后转换导入；视频预设可从“新游戏 → 选择地图 → 第 3 页”进入。零读档第 35 天完成规则引擎通关；[本轮视频、攻城与策略记录](../../docs/video-siege-campaign-0.46.md)。以下 14 张社区图的历史下载来源保持原记录。

已下载并核对 SoD 格式头、尺寸、层数和地形区块。0.42 起，在 **新游戏 → 左下角“选择地图 · 已下载地图”** 可选择这 14 个 H3M、查看 27 层地形概览，并点击“打开社区地图目录”查看原始文件。文件已随 Mac 安装包内置。

0.44 起，这 14 个文件可选择并启动“原图探索”，载入原始地形、物件、阻挡、起点、军队、城镇及部分事件，可探索、拾取、占矿与战斗。入口为 **选择此地图 → 开始原图探索**。0.45 已接入多英雄控制和基础电脑经营/行军，并对 Seven Lakes 完成一次规则引擎的开局到胜利流程（含正常读档重试）；其余地图仍未逐一通关，完整电脑策略、装备、攻城与全部剧情/物件规则尚未完成。详见 [本轮通关与限制](../../docs/kingdom-campaign-0.45.md)。Seven Lakes 因无预设起始英雄，会自动花费 2500 金币招募一名英雄。详见 [支持范围](../../docs/community-scenarios-0.44.md)。
