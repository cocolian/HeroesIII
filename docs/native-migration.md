# C++ 原生迁移记录

主程序改为 C++20。SDL 提供本机窗口、输入、渲染和 macOS 高像素密度窗口；SDL_image 读取现有原图，SDL_ttf 绘制系统中文字体。独立规则库不依赖 SDL，可以在无图形环境运行测试。Homebrew 当前提供的 SDL2 接口包为 sdl2-compat，底层使用 SDL3；本项目调用 SDL2 API。

## 验收结果

- Apple Clang 编译通过，产物：`build/native/HeroesIII.app`。
- 280 项核心检查、14 项资源格式检查和 22 项音频检查通过，包含士气/幸运、等待队列、整数伤害和旧存档迁移。
- 227 个界面通过离屏渲染，包含高清/经典对照图、建筑升级、士气/幸运和原生输入场景。普通和 ASan/UBSan 构建的 PNG 全部一致。

- 开启 AddressSanitizer / UndefinedBehaviorSanitizer 的规则测试通过。桌面窗口已实际验证九阵营选择、要塞城镇、键盘导航与单兵招募结算。

## 0.21 macOS 原生指针桥接

SDL 兼容层的实机记录中，按下位置随点击变化，松开及轮询位置仍为旧值；拖动缺少移动事件。增加仅匹配本窗口的 AppKit 本地事件监听器，将 `locationInWindow` 转为内容视图点数，随事件携带 Shift 等修饰键，使用私有 SDL 用户事件保持与其他事件的顺序。原生源启用时忽略重复 SDL 指针事件；其他平台及离屏检查仍可使用 SDL 后备。窗口外按下不启动游戏捕获，析构时移除监听器。

修饰键快照只在当前事件的分发期间有效，不修改全局 SDL 键盘状态。原生松开使用自身位置，先更新地图、军队或滑块的终点，再执行对应结算；不再要求途中一定有移动事件。缩放与失焦均取消手势。`--save-dir` 隔离实机测试存档/设置，`--input-trace` 提供默认关闭的本地 JSONL 诊断。

640×480、1280×720 和 997×751 窗口检查覆盖留边、点击路线、道路消耗、释放终点平移、往返拖放、Shift 拆分、缩放取消、音量与招募滑块；新增七张图，共 280/14/22 检查及 185 张界面通过，普通与 ASan/UBSan PNG 全部相同。AppKit 桥接随后增加标题栏按下过滤，两构建重编译通过；实机使用最终构建验证。

Mac 992×744 点、1984×1488 输出实测地图平移、路线行军、部队拖放及拆分/合并、滑块招募；松开时原生 Shift 为 3 而 SDL 轮询已为 0，拆分仍正确执行。测试独立存档中枪兵 28→42、金币 10000→9160、兵源 14→0。最后重启正常实例并读取原有自动档，真实存档未变。外接屏、全屏和完整鼠标/触控板组合尚未验收；本轮不增加美术覆盖。官方 API 依据与记录见 `references/input/`，证据见 `data/native/validation-0.21.json`。以下各节为历史状态。

## 0.20 原版特效、成功目标与音效排期

原版资源对应表编译为四种效果、共 70 帧：正负士气、幸运和大难临头。`BattleMotion` 的效果轨道按独立时钟播放一遍，保留每帧画布、裁剪与偏移；不再显示原英雄图标的棕色矩形。负士气触发时同步一次畏缩组。正负士气声音已核对为 `GOODMRLE` / `BADMRLE`，与欢欣鼓舞/悲痛欲绝施法声分开。

四个法术仅在成功应用后发出 `CombatSpellEffect` 快照，抵抗/免疫不伪造成功目标。群体施法在单个片段中并行播放目标轨道，只播放一次 `SpellCast` 声音；动作/AI 等待，选项暂停，播放不修改已提交局面或 RNG。新事件不写入存档，格式仍为 10。新增 10 项核心、3 项音频及 10 张场景，共 280/14/22 检查和 178 张场景通过。

仅使用固定配置及常量中的资源事实，不导入外部引擎实现。当前 100ms 帧间隔和目标脚下锚点仍需原版执行程序校准；其他法术/射弹/英雄施法及完整 2K 特效美术仍缺。来源见 `references/battle/effect-source.json`，表与生成器可离线复现，验收见 `data/native/validation-0.20.json`。0.19 的 600ms 提示与未映射士气声音已被本轮替换。

## 0.19 士气、幸运与存档格式 10

规则拆入 `morale.cpp`，十三种候选技能包含幸运术，已有技能编号不变。阵营/亡灵/技能/生物光环和四法术先求和后限制范围；非生命免疫、牛头人/半身人下限分别处理。每轮最多一次正士气额外行动，负士气失去行动；额外行动等待用独立 FIFO，速度变化不重排。战斗播放在显示提示时暂停规则输入，不改随机状态。普通伤害改用约分后的整数比例，幸运基础加伤在减伤之前相加，最终再取整。

格式 10 添加 `moraleUsed`、`moraleWaiting`、`moralePhase` 及第十三项技能；加载格式 1—9 不抽取新随机数，旧战斗不凭空触发士气。新队列类型、互斥阶段、重复 ID、部队标记和军队容量在替换局面之前严格校验。法师/飞马费用光环在原始军队死亡后仍保留，冒险法术书也显示法师折扣。

英雄图标改为实际数值，四法术接入费用、群体目标、相互抵消、疗伤/驱散和回合到期。战场仍为临时 600ms 图标提示，幸运声音已映射，完整原版特效及士气声音待还原。负士气重新检查、无英雄同城加成、平速轮换及 RNG 未独立校准；不是原版完全一致。研究依据见 `references/battle/morale-luck-source.json`，验收见 `data/native/validation-0.19.json`。

## 0.18 静态建筑重绘与升级图层修正

高清注册表新增三档城防、两档岗楼；只接受单帧 DEF 且逻辑画布必须匹配，原始动画继续播放。派生纹理沿用 128MiB 缓存。四像素内用相邻覆盖色扩展 alpha≤16 的 RGB，保持 alpha 和高覆盖颜色不变，减少透明图缩放彩边。实际尺寸及提示词见 `references/hd-art/README.md`。

生成器原先仅查阵营覆盖对象中的 `upgrades`，漏掉通用城防/议事堂/行会链，造成多级叠加。现合并共享与阵营事实，沿升级链隐藏全部祖先；九城及全部兵营有专项检查。升级截图校验游戏 JSON 不变、原始蒙版采样命中不变、只绘制当前建筑级别。Mac 已验证新构建载入当前自动档、重绘建筑和完整动画底帧；手动/自动档未改写。证据见 `data/native/validation-0.18.json`。

## 0.17 高清重绘与英雄窗口

保留原版 800×600 布局，默认开启首批高清重绘，F7 / 系统选项切换并独立持久化，不改变游戏状态。草地四幅全高分区提供约 2746×1906 的原生覆盖，最小差异边界拼接；城堡改用连贯的 1836×857 整幅稿，原生 2K 目标仍未完成。凯瑟琳大小头像用于英雄、冒险与城镇窗口。采用稿、停用稿和提示词见 `references/hd-art/README.md`。

通用字体按 Retina 物理像素生成，标题采用宋体、正文采用黑体，边框和按钮按布局绘制。旧图块通过边缘重建缓存改善放大采样；透明颜色扩展保留 alpha，GPU 派生缓存上限 128MiB、原图表面缓存 32MiB。经典模式使用原图最近邻。英雄窗口恢复原版装备栏、主属性和八技能格，0.19 起士气/幸运显示实际值，完整宝物系统未实现。

实机发现城镇 DEF 的后续旗帜帧只覆盖建筑局部；绘制小帧前先恢复完整底帧。独立渲染检查同时验证旗帜像素变化和区域外屋顶/墙体不变。L 保持优先读取手动档，新增 Shift+L 读取自动档，避免重启新版时回到较早的手动进度。

## 0.16 事件快照与动作重叠

瞬态 `GameEvent` 附带每次攻击/伤害的部队快照及音效排期标记。播放层由单一移动片段扩展为多轨片段，在命中点应用快照，重叠显示攻击与受击，并按规则事件顺序处理反击、连击、反伤及死亡。尸体末帧、两段转身和方向恢复独立于规则结算，存档格式保持 9。

声音由队列排期后不再叠加原临时间隔；没有动画的施法事件继续使用原间隔。近战中间命中帧及 100ms 基准仍属临时值，远程射弹和全部法术/特技动画尚未实现。当前为 224 核心、14 格式、17 音频与 153 场景通过，普通及 ASan/UBSan 一致。实机只复核启动和旧档，不把离屏通过视为原版或完整鼠标验收，详见 `data/native/validation-0.16.json`。

## 0.15 移动播放与规则解耦

新增无 SDL 依赖的 `BattleMotion`，从行动前战场及结构化事件生成移动片段。规则库返回完整地面路径或飞行端点；事件记录堆栈身份。桌面层使用原始起步/移动/停止组，数量牌和绘制顺序跟随插值位置。移动时阻止后续行动与 AI，选项暂停、战报延迟，新游戏和读取清理队列。

游戏结算、随机流与原格式 9 存档不依赖播放时钟，移动期间保存再载入会恢复已结算的结果。声音事件在各片段边界释放，完整循环与动作同步仍待校准。转身、攻击、射弹、受击、死亡和法术动画未完成；临时基准速度不代表原版时序。

普通与 ASan/UBSan 均通过 211 核心、14 格式、16 音频及 139 场景。实机只验证新构建旧档读取；地图鼠标选择仍偏移，完整实机移动交互没有验收。记录见 `data/native/validation-0.15.json`。

## 0.12 音频与客户端选项

新增纯 C++ `AudioMixer` 和 SDL `AudioEngine`，不引入外部游戏引擎。717 个原始 ADPCM 音效由 SDL 解码，25 首音乐预先转成 PCM；FFmpeg 仅用于离线素材生成。音频独立随机轮转，不改变规则 RNG；结构化游戏事件为有界瞬态队列，旧存档迁移和格式 8 不变。客户端设置独立存放。

原版系统选项皮肤接入部分有效设置，未完成控件禁用。全部音轨/音效解码、混音数学、事件映射、缓存、设置边界及 dummy 输出回调验证通过。原版触发和时序、缺失声音与未开放选项详见 `references/audio/README.md`、`data/native/audio-coverage.json` 和 `docs/parity.md`。

渲染改为保留物理像素画布后呈现，截图读取保留帧，软件后备关闭批处理。SDL 自动逻辑输入缩放关闭，窗口点数及留边由应用换算；实机曾收到正确按下坐标和旧释放坐标，使用按下/移动序列修复按钮命中。新增宽屏、小窗口及原生拖放事件回归；完整实机拖放和所有城镇鼠标入口尚未验收。

当前使用 SDL2-compat 2.32.74、SDL3 3.4.20，离线转换工具 FFmpeg 9.0.2_1。193 项核心、14 项格式、14 项音频及 117 张图形场景在普通和 ASan/UBSan 构建均通过，证据见 `data/native/validation-0.12.json`。

## 0.13 原版 Windows 资源补充

引入有独立大小/SHA256 记录的公开 RoE 试玩包，用可信解包工具仅提取数据。`original_resources.py` 验证档案及派生文件，统一资源覆盖次序，Complete 同名资源优先；自有 LOD/PCX/DEF/SND 解码器不变，未导入其他引擎实现。

## 0.11.0 原版城镇、大厅、堡垒与招募

新增 `town_ui.cpp` 与有界 `H3MK` 蒙版读取器；从校验过的原版 PCX TZ/TO 生成建筑命中区域与描边，保持层次和透明空洞。九城卡片排列、升级链与 HALL 图标来自已固定的事实配置；建设状态由规则库集中判断，提交时再次校验。原版城镇下半区、七生物堡垒、建造确认与数量招募面板替换旧自绘布局。

城镇接入拖放、Shift 拆分、远程驻军内部整理，招募接入滑块、原版最大/购买/取消按钮、七资源价格与接收方栏位检查。鼠标只在正确窗口与捕获按钮释放时结算，失焦清理滑块和军队拖动；Esc 返回正确父窗口。辅助军队升级界面仍保留，尚非原版完整生物信息窗口。

349 组定义中 112 组为原始蒙版/描边、237 组为记录过的前景后备；320 个运行图层使用其中 107 组原始蒙版。六城大厅底图和五城堡垒专用预览底图尚缺，替代规则在 `town-interface.json` 中单列。四张公开实机截图仅用于几何/组成对照，保留来源和校验；没有将有损或缩放截图当作像素基准。

新增 10 项核心回归、28 张图形场景，普通及 ASan/UBSan 构建均为 176 项规则、12 项资源检查与 110 个场景通过。建设及军队服务不允许在战斗/战果/升级待选/结局时结算；合并与招募遵守本项目存档容量，不能把该容量视为原版上限。

Mac 实际窗口验证旧档载入、市场费用确认与建设、堡垒招募 3 名枪兵，金币 9500 → 9320、部队 28 → 31；手动档未改写，自动档仍用格式 8。系统字体、预览锚点、右键/全部状态、驻城英雄、多城列表及完整服务仍待实现。
