# 0.43：Mac 冒险地图手势

按要求对调地图滚动与缩放操作：

| 操作 | 效果 |
|---|---|
| 触摸板双指滑动 | 横向、纵向或斜向移动地图视野 |
| 鼠标滚轮 | 移动地图视野 |
| 按住触摸板后向上拖动 | 放大地图 |
| 按住触摸板后向下拖动 | 缩小地图 |
| 单击地图 | 规划路径，再次点击或按 M 行军 |
| 拖动小地图 | 定位地图视野 |

缩放以按下的位置为中心，在地图边缘受可见范围约束，范围保留为 65%–180%。超过拖动阈值后松手不会变成地图点击；窗口失焦或调整大小会取消按住状态。右栏、资源栏和其他游戏界面的滚动不会改变冒险地图视野，地图列表仍按原有规则翻页。

原生 Cocoa 输入桥接现同时接收应用自身窗口的滚动事件，使用当次事件坐标和小数位移；SDL 兜底入口保留双轴小数处理。位移沿用系统自然滚动方向，不再根据方向标记二次反转，地图每次滚动后立即限制在有效边界。重复的 SDL 鼠标／滚动事件不会再进入原生输入分支。

这次调整针对 Mac 鼠标与触摸板。iPad 触屏仍为单指拖动平移、双指捏合缩放；已做主机合成手指事件回归，尚未做 iPad 真机验证。

## 验证范围

- 四种窗口尺寸：640×480、1280×720、997×751 和 1512×982。覆盖小数双轴滚动、反向滚动、整数滚轮、自然滚动标记、按住缩放中心、只收到松开终点的拖动、连续移动不累计放大、边界、窗口失焦／缩放取消，以及保留路线且不触发行军。
- 保留城镇部队拖放、Shift 拆分、音量／招募滑块、iPad 单指平移与捏合缩放检查。
- 普通、ASan/UBSan 和通用发行版运行 `--pointer-tests`，比较 13 张截图和两份审计记录。普通构建另跑完整交互与练习地图通关流程；通用发行构建运行全部 CTest 与独立应用资源／搬迁／签名验证。
- 在独立 Mac 测试窗口通过原生 UI 自动化验证按住上拖放大、纵向滚动保持缩放比例、按住下拖缩小。横向自动化工具未产生非零横向滚动事件，因此横向部分仅计入合成 SDL 双轴事件验证，没有记为真实触摸板手势验收。

本次没有重跑 0.42 的全部 455 张界面矩阵；此次输入与集成结果单独记录于 [validation-0.43.json](../data/native/validation-0.43.json)，不覆盖历史证据。
