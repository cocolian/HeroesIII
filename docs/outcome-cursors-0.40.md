# 0.40 地图结束与原版光标

最终一战的战报关闭或升级选择结束后，旧代码直接进入主菜单，地图结束信息容易被错过。本版保留战报、升级顺序，随后显示独立的胜利或失败结算。结算显示任务结果、天数、等级、经验，使用原版 DIBOXBCK 皮纹、DIALGBOX 八片边框及确认按钮；玩家确认后才返回菜单。Esc、点窗外和经过一段时间均不会自动关闭。恢复已结束的地图也会显示结果。底图与边框先按整数像素合成，避免宽屏非整数缩放产生接缝，文字继续按 Retina 像素独立绘制。

冒险地图可通行地面显示 CRADVNTR 行走马形，建筑、矿山、资源显示扬蹄访问马形；守军目标或受守卫控制的访问点显示剑。当前英雄、己方城镇分别使用英雄和城堡图标。跨天目标使用原始第二天、第三天、第四天及以后帧；按逐格花费与每天的行动额度估算，尚未预估未来访问马厩或更换部队产生的额度变化。迷雾或不可达地面显示原版金色指针。

战场近战目标使用方向剑，远程目标使用弩，超过有效射程且兵种承受距离惩罚时使用断弩；可达空格显示步行或飞行图标。友军显示查询图标，不可达目标显示禁止；忙碌阶段显示沙漏。有效施法目标使用 CRSPELL 动画，非法目标不提示可施法。所有图标采用原始素材各自的点击热点，尺寸不随地图缩放改变。

近战范围、落点和移动距离由同一个只读 AttackPlan 计算，悬停不改变生命、回合或随机数。方向剑指向当前引擎实际选择的攻击落点；尚未实现原版通过鼠标靠近目标不同边缘选择攻击方向的功能。

矿产悬停的访问光标与地图物件动画是两个系统。原始 DEF 中金矿 16 帧、金币 8 帧，木材/矿石堆和部分矿山只有一帧；本版沿用这些原始帧，不为静态矿产添加闪动。风车、水车、河流/海水的帧与调色板动画继续保留。

## 验证

普通、ASan/UBSan 和 Mac 通用发布构建均通过 310 项规则、14 项资源格式、8 项 H3M 格式及 22 项音频检查。三种构建各完成 391 张场景截图与 20 份流程审计，所有 PNG 哈希及审计内容一致，包含 1280×800 非整数缩放的结算边框像素检查。

自然流程从新游戏开始，按正常收入建设、招募、探索与施法，游戏内第 18 天通关：62 步移动、4 场战斗、4 次魔法神箭、2 次升级选择、2150 经验；在胜利结算确认后才能返回菜单。另测全军覆没、战报和升级顺序、恢复已结束地图及无操作时保持结算。

安装包包含 arm64/x86_64 两种架构，最低 macOS 14，11199 个运行文件已校验；应用严格临时签名校验及 DMG 校验通过。仍未经过 Developer ID 签名或 Apple 公证。

记录见 `data/native/validation-0.40.json`；截图与哈希见 `references/validation/0.40/`。以上为隔离临时目录中的自动流程，本轮没有真人鼠标全程通关或 iPad 真机验证，不触碰用户正在玩的存档。
