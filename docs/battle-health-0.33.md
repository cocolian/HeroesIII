# 0.33 战斗生命显示修复

此前战场兵种旁的紫色横框是固定宽度的数量底框，没有生命值进度显示。检查规则引擎后，近战、远程、反击和魔法均会扣除总生命值；未击杀一只生物时，数量保持不变。

现在数量底框下方单独显示总生命条，以开战时的数量乘单体生命为固定上限，受击帧到达时更新。减员后不会重新变满，濒死部队保留最小可见长度，死亡动作中归零，治疗可恢复。绿色、黄色和红色分别表示高、中、低生命；这条生命条是按用户反馈新增的辅助显示，不作原版界面逐像素一致的声明。

悬停单位所在格可查看准确的总生命数值。命中帧还会显示实际扣除的生命和减员数，音频取走事件后仍保留文字反馈。伤害公式、随机数、回合队列及存档格式没有改变。

固定案例：10 个枪兵攻击 2 个骑士，骑士从 200 生命降到 189，数量仍为 2；渲染像素检查确认血条由 28 像素缩短至 26 像素。Mac Retina 实际窗口也完成同一攻击，观察到血条缩短以及“受到 11 点伤害，损失 0 个”的反馈。测试使用独立应用与隔离进度目录，原游戏窗口保留。

自动验证覆盖经典/高清模式、未减员伤害、减员、反击、远程、魔法神箭、死亡归零、治疗和仅剩 1 生命的情况。规则测试 290 项、资源格式 14 项、音频 22 项均通过；开发版及 ASan/UBSan 各通过 101 张界面检查，发行版完整流程通过 328 张。共享图片 99/101 相同，两张图鉴在完整/重点流程中选择了不同内容；八份共享审计一致。固定练习图仍在第 18 天通关，62 次移动、4 场战斗、4 次施法、2150 经验。

证据：[验证记录](../data/native/validation-0.33.json)、[截图和日志](../references/validation/0.33/)、[生命值审计](../references/validation/0.33/battle-health-audit.json)。Mac 安装包支持 arm64 / x86_64、macOS 14 及以上，临时签名、未公证；本轮未重测 Intel 或 iPad。
