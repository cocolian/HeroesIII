# 0.30 原图收集与画面对照

目标仍是经典 Complete / 死亡阴影。0.30 是一次原图校对与渲染改进，**尚未达到原版全部功能、逐像素或逐帧一致**。经典模式使用原始素材；F7 可切换此前选择的高清重绘模式。

## 原图资料

本次收集 35 张公开游戏截图，35 个不同文件内容，其中 2 张与项目已有大厅、堡垒参考图相同，新增唯一图片为 33 张。

- [GOG Complete 商品页](https://www.gog.com/en/game/heroes_of_might_and_magic_3_complete_edition)：20 张完整构图 JPEG，8 张为 1600×1200，12 张为 710×533。后者接近 4:3，不能标为原生 800×600 或 2K 素材。画面涵盖八种城镇，没有元素城的完整城镇截图。
- [2000 年 Linux 游戏实测文章](https://linuxgazette.net/issue60/misc/andreiana/index.html)：15 张，13 张为 640×480、2 张为 800×600。含冒险迷雾、英雄、城镇、大厅、堡垒、野战、攻城和战报；其中一张地图有作者画的红圈。

[原图画廊](../references/original-review-0.30/index.html)、[并排对照](../references/original-review-0.30/comparison.html)和 [来源/尺寸/SHA256](../references/original-review-0.30/sources.json)均可本地打开。原文件未改绘；商店横向裁切版另放在 `renditions/`，不用于完整构图验收。社区魔法书图片确认为 HotA，放入 `excluded/`，没有混入经典版基准。已有加宽 HD Mod 魔法书也不作为经典窗口尺寸基准；本轮仍缺可靠的经典魔法书实机截图。

这些 JPEG 经网站压缩或缩放，地图、语言、玩家颜色和局面也不同。因此只核对组件、位置关系和外观，不计算虚假的“原版像素一致率”。

## 本轮修改

| 部分 | 修改 | 当前限制 |
|---|---|---|
| 冒险迷雾 | 接入原版 TSHRC 星点全遮罩及 TSHRE 柔化边缘；深处未知地形不绘制，边界保留遮罩混合所需底图 | 使用本项目邻域匹配与变体选择，尚未按原版同地图逐格校准 |
| 战场英雄 | 加入蓝方骑士 CH00 和旗帜 CMFLAGL | 当前只有凯瑟琳；没有英雄施法、战败等完整动作。中立敌军不添加英雄 |
| 部队数量牌 | 使用 CMNUMWIN 边框与紫色内底、白色居中数量 | 紫色由现有底图近似调色；原始调色板和位图字体尚未还原 |
| 当前行动部队 | 删除方形选中框，按精灵不透明身体生成一像素金色轮廓，排除低透明阴影 | 轮廓算法不是原版调色板选中机制，细节仍有差异 |
| 构建一致性 | 开发、ASan/UBSan 与发行入口统一固定版本静态 SDL2 依赖 | 此前开发用 SDL2-compat/SDL3 时，180% 缩放的遮罩表现与发行版不同；未据此断言外部库缺陷 |

保留 0.29 的原版 ADAG 路线箭头、终点叉标、红绿行动力状态，以及 96×64 英雄/旗帜画布和地图缩放比例。城镇/战斗/弹窗保持原版构图；全屏冒险地图继续扩展可见地块。

## 验证范围

- 发行、开发、ASan/UBSan 三组均通过 284 项核心、14 项资源格式和 22 项音频检查。
- 发行版完整离屏流程生成 298 张 PNG；开发和 ASan/UBSan 重点流程各 71 张，均成功，未报告 sanitizer 错误。
- 三组共有的 71 张中，69 张 PNG 的 SHA256 一致；其余两张为图鉴的高清/经典页。完整流程此前遍历了图鉴，重点流程从默认兵种开始，选中内容不同。五个相同场景 JSON 审计一致；不声称全部图片相同。
- 新增全部 21 个 Scene 的经典模式截图；65%、100%、180% 缩放分别检查未知区域保持黑底与星点。截图渲染不改变游戏状态。
- 固定 36×28 练习图通过真实规则与客户端操作处理自动通关：第 18 天、62 次移动、四场战斗、四次施法、2150 经验、两次升级选择。没有注入资源、军队或取消迷雾。这不是原版战役通关。
- 本轮 Mac 实际窗口观察了新游戏、经典模式全屏地图、城镇和大厅，留存三张截图。随后电脑控制工具的鼠标操作返回 `noWindowsAvailable`；重新定位窗口后仍未恢复点击。本轮没有完成实机施法/战斗复验，自动流程也不替代这项实机证明。原有 0.27 实机通关记录保持独立。
- Mac 包包含 arm64/x86_64、11117 个核验资源文件，严格临时签名有效，只依赖系统动态库、禁用工程目录后备；最终 DMG 校验通过。本轮没有重新验证 Intel 运行或 iPad。

完整证据：[validation-0.30.json](../data/native/validation-0.30.json)，截图及日志：[0.30 验证目录](../references/validation/0.30/)。安装包为本地临时签名开发版，未做 Developer ID 签名或 Apple 公证。
