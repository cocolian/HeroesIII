# 多英雄、基础电脑回合与社区地图通关 · 0.45

新增酒馆付费招募、多英雄切换、相邻会面交换部队、独立的行动力/魔法值/经验/装备状态。冒险地图左栏选择英雄，N 或头盔按钮选择下一位未休眠英雄；上下箭头翻页。右栏可翻页选择已拥有的城镇，远程建设、招募驻军；英雄需要实际入城才能接收部队。八位冒险英雄的招募上限和最后一名士兵约束均保留。

导入地图保留独立势力，不再把全部电脑折成同一方。基础电脑回合使用各自的金库、视野和军队，进行建设、市场交易、招募、购船、探索、占矿、夺城及战斗。战败后仍拥有酒馆和资金的电脑会重新雇佣英雄；没有额外注入资源或部队。地图预置英雄的巡逻范围、初始法术、装备与剧情对象身份保留，避免行军后丢失“击败指定英雄”的任务标记。

剧情事件补读原图 `guardians.message`，增加可翻页的剧情记录。修复事件文字缺失导致异常、未支付交换费用却领取奖励、己方驻防要塞被误当作敌军，以及最后一名英雄战败但仍有城镇时被错误判负的问题。复跑还发现并修复原图事件教授第九项辅助技能导致状态校验失败的问题：新技能受八项上限约束，已有技能仍可升级，其他奖励照常发放。资源、宝物与剧情物件的完整兼容仍在推进。

海陆规划使用两种交通状态：既计算陆地路线，也计算登船、航行和合法海岸下船后的路线。跨日保留目标，实际登船/下船仍消耗剩余行动力。修复反复往返同一海岸；船坞按正常金币与木材费用购买空船。英雄的原始访问格与精灵画布重新对齐，八种势力旗帜和地图归属颜色均接入。

## 完整实测的含义

使用下载的 Oscar Sedell 版 Seven Lakes，原始文件 SHA256 为 `7c40c456bc04d55fd709942cb387f42e42ec1b7d0f428c45ce7dbd77afa38c15`，实际载入 144×144 地形、6738 个原始对象及其属性。没有替换成练习地图。该图原本没有预置起始英雄，沿用当前导入适配：各势力均从自己的资金中支付 2500 金币招募一位基础英雄。

完整流程由原生规则引擎执行，依次探索、经营、交易、招募、行军、战斗、施法、占城，直到原图的标准胜利条件成立。操作者为自动测试程序，不能据此声称人手在 Mac 上逐个点击了全部回合。

测试使用正常保存/读取来重试失败路线，明确记录读档次数。路线规划器只记住实际遇到并战败的位置，用于后续选择另一条合法路线；它在临时规划副本中避开危险点，不改动实际地图阻挡、迷雾、资源、部队、英雄坐标或战斗结果。动作日志保留读档标记，统计中的累计步数与施法次数包含被读档撤回的尝试，不伪称一次生命通关。

最终版本在第 **322 天**达成标准胜利，剩余敌方英雄和城镇均为零，拥有 27 座城镇；进行了 22 次正常读档重试。成功时间线包含 506 场玩家战斗，累计尝试包含 9655 步移动和 553 次施法，剧情记录保留 656 条。最终统计、逐日记录、战斗记录、完整结算状态及界面核验见 `data/native/validation-0.45.json` 和 `references/validation/0.45/`。普通、地址/未定义行为检查和通用 Mac 构建分别运行规则与多英雄界面检查；完整地图结算还会在原生界面显示并确认返回主菜单。界面核验修复社区地图结算误写“黑鸦堡/边境练习图”的遗留文字，战报与升级页改用实际地图结果和英雄名称。

## 仍存差异

这是基础电脑和剧情兼容的开发版本。电脑尚未具备原版完整的冒险法术、外交、装备搭配和战术施法决策；部分物件、城镇定时事件、英雄职业特长及全部兵种能力仍未实现。攻城目前使用现有战斗场地，城墙、箭塔等完整攻城规则仍缺。完成这一张地图不表示其他十三个文件已全部通关，或与原版功能、画面逐项一致。
