## 发现并修复

1. **战报显示无效的“返回”按钮**：原代码先绘制再删除它的响应区域，导致按钮能悬浮高亮却无法点击。标题栏现在支持不显示返回按钮，战报只提供“继续”；同样清理升级选择窗口的无效返回按钮，选择规则不变。
2. **战后地图沿用弹窗鼠标位置**：“继续”位于地图下边缘，回到地图后旧位置立刻触发边缘滚动，镜头偏离英雄并影响后续点击目标。战报确认现在居中英雄、清除旧指针位置和滚动计时；收到新的鼠标事件后才恢复正常指针交互。
3. **地图宝物使用“剑”字占位**：改用已经从核验试玩包提取的 `AVA0008.def` 剑形地图精灵；原始逻辑画布 64×32，按当前地图缩放绘制。仅替换示例宝物的表示，现有 +2 攻击和存档数据不变；它不是完整原版宝物属性、装备或背包系统。

数量牌在近战时靠得很近，精灵/数量牌的原版锚点仍待校准，本轮未把该项宣称为已修复或原版一致。
