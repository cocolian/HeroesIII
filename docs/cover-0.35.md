# 0.35 死亡阴影封面

启动菜单已使用《死亡阴影》的剑、半人半骷髅、月夜墓地及英文副标题构图。此前使用的蓝色天使画面属于《埃拉西亚的光复》，版本不符。

背景采用公开保存的 800×600 无按钮图像，固定到素材仓库修订；来源和 SHA256 见 [source.json](../references/cover-review-0.35/source.json)。另用中文《死亡阴影》菜单截图核对构图。该文件来自社区保存的版本，未按原版 LOD 校验，不声称原始文件逐字节一致；没有 AI 改绘，也没有把原图称为原生 2K。Retina 沿用物理像素渲染和 4:3 菜单视口。

右侧菜单继续提供目前已实现的新游戏、读取、图鉴、继续和退出；本次使用干净背景避免旧语言菜单文字重叠。菜单控件仍是当前项目样式，完整原版图形按钮仍待对照。

开发和发行包各通过 107 张界面检查，全部共享 PNG 散列一致，包含经典/高清封面；发行包核心、格式及音频检查通过，资源中包含新背景。固定练习图通关回归通过。本轮未新增规则测试或重新运行 sanitizer，未操作用户正在运行的游戏窗口。

Mac universal PKG/DMG 支持 macOS 14 及以上，临时签名、未公证；安装后重启生效。证据：[validation-0.35.json](../data/native/validation-0.35.json)、[封面预览](../references/validation/0.35/ui-menu.png)。
