# 产品检查与本轮优化（0.24.0）

当前产品是 C++20 / SDL 的 macOS 可玩开发版本，保留原版 800×600 逻辑构图并按 Retina 物理像素绘制。它尚未达到《英雄无敌 III Complete / 死亡阴影》的完整功能、画面或动画一致性；已有数据条目和成功渲染的画面不等于对应系统全部完成。

## 当前能玩到的内容

演示关卡为 36×28，使用一个英雄、一座可管理城镇；新游戏可选择九阵营。已有探索、寻路、资源/矿场访问、每日收入、建设、七栏军队与驻军、招募升级、市场、魔法行会、英雄成长、战斗、战报和本项目 JSON 存读档。九阵营支持各自建设和兵种，不能据此理解为同一局已经支持多城管理。

基础数据覆盖 141 种生物、126 座兵营和 70 项法术目录，47 项战斗法术有规则，另外 23 项效果尚未开放。士气/幸运、十三种候选技能及部分生物能力已进入计算，全部技能、英雄职业/特长、宝物、能力及原版随机/取整细节仍有缺口。128 种生物有原始 DEF，另外 13 种缺完整动画。

画面已混用原版试玩素材和重绘图。当前高清资源含草地战场、城堡地景、凯瑟琳头像、十三幅城堡静态建筑，以及本轮四级议事堂主体；界面边框、小图标、兵种和其他八城等仍有明显旧分辨率。城堡地景源图仅 1836×857，导出 2560×1920 截图不代表整屏源图达到 2K。

## 本轮发现与已落实的改进

| 检查项 | 发现 | 0.24 处理结果 |
|---|---|---|
| App 识别 | 应用缺少专用图标 | 内置 image_gen 生成原创蓝金城堡图标，导出十个 16—1024 像素表示，ICNS 接入两个应用；Finder 简介已显示新图标和版本 |
| 议事堂清晰度 | 建筑和旗帜一同保留低清素材 | 四级主体独立重绘，保持原画布、位置、升级链和点击入口；旗帜继续播放原十帧 |
| 动画合成 | 整块贴回原运动区域会露出低清墙面矩形 | 改为蓝金布面的近似透明蒙版，新主体保持可见；没有将原背景矩形作为当前方案 |
| 截图可重复性 | 前序读档提示按真实时间消失，影响一张定时截图 | 在建筑测试捕获开始时清除瞬时提示，最终两构建全部 PNG 一致 |
| 存档保护 | 实机检查可能改变正常进度 | 使用隔离的展示存档，结束后恢复正常实例；真实手动/自动档 SHA256 未变 |

旗帜仍使用原分辨率，颜色/邻域蒙版只能近似保留轮廓和阴影，100 毫秒/帧尚未与原版校准。四幅主体不是完整建筑动画重绘，也没有把所有新绘细节认定为原版逐像素一致。图标是本项目原创图标。

217 张 PNG 逐文件相同，两类审计 JSON 也相同。新增十六张图覆盖各级议事堂经典/高清及旗帜中末相位；检查全部十帧、区域外主体稳定、原不透明蓝色布面、无旧墙面矩形、父裁剪、元数据回退、升级互斥、密度和游戏/RNG 状态。这些是实现回归，不是与商业原版运行程序的全面对照。音频使用 dummy 输出，ASan 设置 detect_leaks=0。

Mac 实机确认 Finder 图标及版本，并在独立展示档点击内政厅进入大厅，未执行建设/购买。展示档为预先配置的美术检查局面，没有当作正常建设流程验收。随后正常启动、读取当前自动档，在英雄窗口观察到移动力 897、军队 28/16/4；最后停留在正常城镇画面。正常英雄位于 9,18，未入城时访问英雄军队栏为空是当前规则行为。真实手动档版本 1、自动档版本 9 均原样保留；运行时格式仍为 10。

## 后续优先级

1. **完整对局基础**：多英雄、多城镇、所有权/玩家回合、英雄雇佣与战略 AI，再验证经济、访问和战斗之间的完整循环。当前单英雄演示结构是主要功能限制。
2. **原版内容与规则**：H3M 和战役、地图事件与胜负条件、攻城/战争机器、全部技能/特长/宝物/兵种能力及其余法术；多人、随机地图与编辑器也尚未实现。
3. **整屏美术与交互**：统一界面边框/小图标与字体密度，补城堡其余建筑、八城和生物动画，逐屏校准轮廓、遮挡、右键/悬浮状态及原版时序；旗帜也需要真正的高清帧。
4. **独立 macOS 发行包**：目前可运行的 .app 仍加载 Homebrew SDL 动态库和外部项目素材，默认数据根目录包含构建时的绝对路径。需内嵌依赖/资源、改相对寻址，再进行异机、外接屏与全屏验证；当前不能按独立安装包分发。
