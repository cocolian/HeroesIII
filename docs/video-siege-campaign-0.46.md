# 0.46 视频地图、攻城与电脑策略实测

本轮选取[奔跑的脚丫RunningFoot 的《死人和被埋葬的人》完整视频](https://www.bilibili.com/video/BV1vu41177kZ/)，下载对应的官方 **Dead and Buried** 地图。两次相同种子的最终规则引擎回放均从第 1 天走到第 35 天胜利，零读档，动作审计一致；这不是全程人工鼠标操作，也没有达到所有原版规则、画面细节一致。

## 在游戏中进入

**新游戏 → 选择地图 · 已下载地图 → 第 3 页《死人和被埋葬的人》→ 选择此地图 → 视频开局 · 元素城 / 200% → 开始原图探索**。视频预设使用 Lacus（拉克斯）、元素城、200% 零资源开局。其余地图保留各自的既有导入方式。现有 15 张下载地图和 29 层地形预览。

地图源文件为 `maps/community/dead-and-buried/1.h3m`，36×36、地上/地下两层。来自[HeroesWorld 官方标准地图合集帖](https://heroesworld.net/topic/8850/list-of-standard-maps-for-heroes-3/)，是俄文版 RoE 地图，视频是中文版 SoD/HD mod。原下载保留不变；使用公开的 HeroWO h3m2json 转换为解析器支持的 SoD 格式。独立核对了全部 755 个对象的坐标、类别、子类型、图像名，以及 2592 个地形格的原始七字节记录，没有替换成练习地图。详见 [转换检查](../references/maps-0.46/conversion-audit.json)。这项检查不等于所有对象属性和玩法均已完全兼容。

## 本轮修复

- 城墙、城门、飞行越墙、城门桥阻挡、护城河/塔楼地雷、箭塔和自动投石车接入攻城。英雄驻城与无英雄驻军均使用城防；修复攻击驻城英雄变成野战、驻城英雄战败后城镇未转属的问题。
- 按威胁、预估损失和反击风险选择攻击目标；电脑英雄使用自己的法术、魔法值和每轮施法额度。副英雄优先将部队运给更强的主力。
- 为船只保留正常购买预算，补上船厂规划和通道重访；修复出口英雄占位与最后英雄阵亡后经营不断花光重新雇佣费用的问题。
- 接入城镇定时事件的资源、建筑和增援；按原始玩家名单分别发放人类/电脑事件。事件执行标记跨保存、读取保留，避免重复领取。修复时限、指定城镇/英雄失败条件及初始英雄身份记录。
- 原版玩家颜色用于界面边框、资源栏、英雄旗帜、船旗和小地图；头像按阵营职业及元素城独立编号解析，覆盖 144 名常规英雄的大小头像；战场格横向原点校正一格。九阵营攻城背景、城墙、破损状态按原版坐标绘制，并去除透明色背景。

## 实测对照

| 项目 | 本轮当前策略 | 同版本旧战斗策略 | 视频玩家 |
| --- | --- | --- | --- |
| 人类起始预设 | 元素城 / Lacus / 200% | 相同 | 元素城 / Lacus / 200% |
| 结果 | 第 35 天胜利 | 第 75 天失败 | 第 19 天胜利 |
| 读档 | 0 | 0 | 无法从剪辑严格判定 |
| 我方显式战斗 | 14 场，12 胜、2 败 | 24 场，12 胜、12 败 | 未逐场转录 |
| 我方移动计数 | 819 | 1248 | 未逐格转录 |
| 最终城镇/敌方英雄 | 我方 3 城，敌方 0 英雄 | 失败 | 消灭所有敌人 |

旧战斗策略是“优先最近目标”，其余冒险经营、规则和电脑对手与当前策略相同，因此只用于评估当前引擎中的战斗决策改进。不能据此称为战胜原版 AI。新策略虽然赢了，但比视频多用 16 天（约 84%），期间损失英雄、丢城再夺回，主副英雄协同、守城和路线效率仍有明显差距。

完整回放只调用正常经营、购买、招募、移动、访问、战斗和升级接口，没有额外注入资源/军队、修改地图碰撞、揭雾或传送，也未读档重试。敌方记录了 52 个英雄回合、9 场自动战斗且全部胜利，累计花费 73874 移动力、58 魔法值；记录包含正常补给导致的移动力变化，不能等同于画面步数。最终我方持有 3 座城镇，敌方英雄和城镇均为 0。存档与逐步动作保存在[实测证据](../references/validation/0.46/current-campaign/campaign-audit.json)。

这张地图没有全局定时事件，不能用它证明所有剧情脚本已兼容。城镇脚本、人类/电脑分发、重复周期与保存恢复另外使用真实格式的最小规则场景检查。

## 画面对照范围与剩余差异

[视频和当前画面对照画廊](../references/video-review-0.46/index.html)保留 23 个带时间点的原始视频帧；本轮另外生成九阵营三种城防级别及破城、八种船旗和实际地图开局/攻城/胜利截图。视频 SHA256、地图 SHA256 和画面来源均已记录。

已经校正原版 800×600 战场格起点、城防静态布局、原始素材透明色、红方调色板和英雄头像。全屏冒险仍按窗口扩展地图，不放大固定地块来伪装扩大视野。视频使用 HD mod，在大冒险界面上覆盖 800×600 战斗窗口；当前战斗仍采用居中的固定构图，外围显示行为不同。

仍未完全一致的细节包括：防守方在当前引擎左侧时使用镜像城防；开门暂借破门图，没有完整升降动画；投石车没有可操作的器械生命和弹道动画；箭塔伤害与隔墙射击线为近似规则；部队生命条是自定义附加显示；场景选择、酒馆、英雄会面、剧情记录及最终积分榜尚未复刻原窗口；中文英雄名、城名与全部专长、战术布阵、冒险法术和部分地图物件仍不完整。

当前“200%”预设只近似人类的零资源开局：这次实现中电脑的起始银行也为 0，原版电脑随难度获得的资源、收入与其他加成未完整接入。因此 35 天是当前开发规则下的通关结果，不能视作原版 200% 难度成绩。原视频随机种子未知，兵力、法术和升级结果不同，不能进行整屏像素一致率或宣称 AI 与视频完全等价。九阵营攻城素材使用已收集的 [Sprite Database 原始精灵拆图包](https://spritedatabase.net/files/pc/2195/Background/siegebg.zip)，其中可用的城堡/墓园/地下城素材优先使用已验证官方 Demo 资源；布局依据 [VCMI 原始阵营配置](https://github.com/vcmi/vcmi/tree/develop/config/factions)。
