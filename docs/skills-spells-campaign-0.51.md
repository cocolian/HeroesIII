# 0.51 技能、法术、界面与 Seven Lakes 实测

本轮完成六项辅助技能的实际流程，并把上一轮审计的 23 项未开放法术和可建设特殊建筑服务接入游戏。目录中的实现标记仅表示有执行路径，不代表已经与原版的每个组合、画面和时序一致。

## 六项技能

| 技能 | 已接入的行为 |
| --- | --- |
| 外交术 | 野兵性情、相对兵力、同类部队、免费／付费加入、逃走／追击、拒绝加入后的反应；在剩余部队招募价的一半基础上计算投降费用折扣及相关宝物 |
| 弹道术 | 独立投石车单位，按技能决定射数、目标命中率和城防伤害；玩家可以选择城门、城墙和箭塔 |
| 鹰眼术 | 战后只学习敌方实际施放且符合等级、智慧术与魔法书条件的战斗法术；概率、宝物和技能特长进入计算 |
| 招魂术 | 按每支被消灭的活物计算数量和生命限制；技能特长、招魂宝物、鬼王斗篷、招魂塔、墓园圣杯加成；升级兵种折算；满编时选择替换或放弃 |
| 学术 | 两名相邻己方英雄会面时双向交流法术，分别检查魔法书、学术和接收者智慧术；重复会面不会重复收费或生成奖励 |
| 战术 | 按双方技能差给予 3／5／7 列布阵区，检查双格单位与障碍；下一支部队／开始战斗使用原版按钮；宝屋战不布阵 |

156 名英雄的初始技能、法术、职业与特长身份已按固定数据编译；初始军队改为各英雄独立的兵种和数量范围，三支初始部队的出现概率为 100%／88%／25%。地图预设军队与技能仍优先使用地图数据。

## 法术、城镇与界面

- 70 项原版法术均有执行路径，包含 60 项战斗与 10 项冒险法术。新增控制权归还、生命阈值、流沙中止行军、地雷单次触发、魔法墙阻挡／伤害、城防破坏、双目标瞬移、城镇传送、船只操作、飞行与水面移动。
- 91 种普通战场障碍的原始素材与阻挡形状已编译。攻城、宝屋和船上战斗使用各自布局。隐藏陷阱不会提前暴露给敌方；地面行走逐格触发，飞行不触发地面陷阱。
- 26 项持续法术使用原始特效帧；四项士气／幸运表现继续使用原有专门映射。动画帧间隔尚未按原版执行程序逐帧校准。
- 铁匠铺／弩车作坊、宝物商店、转换场、魔力漩涡、召唤之门、城堡之门、金库、神秘池塘、城镇士气／幸运和守城主属性建筑进入实际计算。
- 增加装备替换与卸下、背包翻页、技能说明、满编招魂确认、投降／逃跑确认、资源赠送和王国总览；修正英雄职业精灵、城镇名称、势力旗帜和陷阱画布尺寸。
- 圣杯可挖出、携带、入城建造，九阵营均显示原始圣杯建筑；基础收入、周增长、墓园招魂、城堡士气、壁垒幸运、部分守城主属性、塔楼侦察和元素城法术教学已接入。所有特殊圣杯效果仍需扩大原版组合验证。

## Seven Lakes

使用下载原图 `seven-lakes-1`，原文件 SHA-256 为 `7c40c456bc04d55fd709942cb387f42e42ec1b7d0f428c45ce7dbd77afa38c15`。按正常探索、经营、交涉、招募、升级、运兵和战斗运行，没有向游戏注入资源、军队、迷雾或地图碰撞修改。

**最终代码验收：简单难度、城堡、阿德拉开局，第 621 天胜利，零读档重试。** 全程 621 个日结记录、246 场胜利战斗、18,428 次移动、614 次玩家施法及 2,618 次访问。记录另外保留 66 次正常战败、逃跑或投降，其中包含城镇驻军被攻破；没有因个别英雄战败回滚王国。酒馆不主动增招运兵英雄，地图中正常获救的英雄仍参与行动。第 620 天攻下最后一座敌城，第 621 天由获救英雄击败最后一名敌方英雄，最终拥有 18 座城镇。

该结果使用本轮最终的规则、电脑经营、每周增长和寻路实现。早期第 377 天／597 天的通关只作为开发历史，不替代最终验收。当前成绩不能解释为原版高难度水平，自动策略也还没有与视频打法等效。

修复的阻碍包括：原版难度开局资源混用、同阵营重复升级兵占满栏位、无收益酒馆／船厂访问循环、把空船当作目的地，以及自动战斗双方无限换位。主力满编时先把新兵招入驻军再合并或交换；规划援军收益时保留招魂兵种栏位，避免主力等待无法交接的部队。

战略寻路可以评估清除安全守军之后的目标，并链接实际访问过的传送门和地上／地下路径；实际执行的路线仍截断在第一场战斗、关卡、传送或上下船处。未知传送出口不提前进入规划，未击败的守军仍会按正常移动规则拦截。主力识别跨地图层与陆海状态，运兵与会面仍检查实际位置。

投降费用按原版先取剩余部队招募价的一半，再计算外交术／宝物折扣。投降保留部队，逃跑只带回一名该英雄的原始初始兵种；酒馆重招保留已经消耗后的魔法值与当日行动力，旧周逃跑英雄不会永久占用候选池。

完整记录：`references/validation/0.51/seven-lakes/campaign-audit.json`；最后状态：`references/validation/0.51/seven-lakes/final.json`。审计程序只调用正常游戏动作；可选的读档逻辑只记住真实失败过的威胁，本次没有使用读档。

此前 0.50 的 Dead and Buried 通关记录仍保留为历史证据。本轮修正了原版 200% 开局电脑资源后，原视频条件的自动策略尚未复现视频的 19 天表现，不能用历史结果替代当前表现。

## 验证与证据

新增 `native_secondary_skills`（80 项）、`native_completion`（449 项）、`native_spell_completion`（65 项）三组回归，当前合计 16 组。原生、通用发行与 ASan／UBSan 三种构建均通过 16 组测试。全套原生界面回归为 478 个场景，新增专项界面为 36 个场景；15 张下载地图共 72 类 Site，没有对象进入通用未实现分支。新增 36 张界面在普通、发行和 ASan／UBSan 构建中逐像素一致。另通过 64 个英雄行走帧可见性与三种窗口尺寸的原版返回按钮点击检查；本机固定场景平均空闲帧约 8.28 毫秒，不能据此保证全游戏帧率。界面回归使用临时目录，不覆盖个人存档。构建、界面与地图记录归档在 `references/validation/0.51/`，汇总见 `data/native/validation-0.51.json`。

```sh
cmake --build build/native -j 6
ctest --test-dir build/native --output-on-failure
build/native/h3_campaign /private/tmp/heroesiii-seven-check 0 9 0 solo
build/native/h3_feature_audit /private/tmp/heroesiii-feature-audit.json
```

## 尚未等同于完整原版

战役与联机、全部英雄和生物特长、组合宝物组装、完整职业升级概率、地图团队关系与所有自定义剧情边缘情况仍须继续实现或核对。部分系统选项、冒险移动插帧、飞行落地表现、攻城特效、法术精确时序及全部屏幕的像素位置尚未完成原版逐屏对照。70 项法术的基本行为已经接入，但不宣称所有相互作用均已验证。

本轮不会把“没有落入未实现占位分支”当作“完全复刻原版”。
