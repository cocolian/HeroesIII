# 0.48 英雄窗口、地图层级与运行性能

英雄窗口右下角恢复原版 `hsbtns.def` 确认按钮。原界面内坐标为 `(609,516)`，加上当前背景偏移 `(64,7)` 后，按钮矩形是 `(673,523,52,36)`。绘制和点击共用此矩形；Enter、Esc 均关闭英雄窗口。参考 [VCMI 的 CHeroWindow 实现](https://github.com/vcmi/vcmi/blob/develop/client/windows/CHeroWindow.cpp)，本次使用的源码快照保存在 `references/hero-performance-0.48/CHeroWindow.cpp`。神行靴等原版宝物名称也加入离线中文词典。

## 英雄被山崖遮住的原因

在报告进度 Wayfarer 的 `(9,42)` 位置，旧版八个方向、每方向八帧的英雄像素贡献均为零。附近 `avxcf0.def`、`avxcf2.def`、`avxcf4.def` 山崖的 H3M 模板带有 `is_ground=1`。此前导入与存档丢失此标记，按物件锚点纵坐标排序后，山崖覆盖了英雄和旗帜。

现在保留每个物件／装饰的地面层标记，先绘制地面层，再绘制路径和普通前景。树木等不透明前景继续按原有纵向层级遮挡英雄。旧进度缺少标记时，按地图、精灵、锚点和地上／地下层恢复，不需要重新开局。存档格式仍为 15。

恢复数据由现有 15 张地图的原始模板生成：2776 条地图内精灵默认值，加上 13 条坐标特例。同名精灵在不同位置可能属于不同层，因此不能仅按文件名猜测。生成器为 `scripts/generate-ground-layers.py`，源文件校验值见 `references/hero-performance-0.48/ground-layer-provenance.json`。

## 减少运行停顿

- 自动保存使用独立线程和游戏快照，连续行走时最多每秒提交一次；保留一个正在写入的快照和一个最新待写快照。停止行走时提交最后状态，正常退出、读档和进入后台前等待写完。手动保存仍立即执行。
- 寻路每次建立物件与野兵警戒区域索引，避免在每个搜索节点反复扫描全图物件。保留阻挡、斜向通行、魔法泉双入口与野兵触发规则。
- 地形只绘制视野内的地图块。预先缓存精灵尺寸与访问点，视野外物件在加载纹理、排序及显隐检查前剔除。
- 开发启动脚本默认使用 `RelWithDebInfo` 优化构建；未聚焦窗口降低刷新频率，最小化时暂停绘制。

同一份 Wayfarer 进度包含 2145 个物件和 17450 个装饰。软件渲染测试的发布构建结果如下；它们是该样本的重复平均值，不代表所有地图或实机帧率。

| 测量 | 修复前 | 0.48 发布构建 |
| --- | ---: | ---: |
| 同一目标寻路 | 0.357 ms | 0.043 ms |
| 保存序列化／写盘 | 107.2 ms，主线程 | 106.2 ms，后台线程 |
| 20 次连续行走保存请求的平均提交时间 | 未测 | 0.037 ms |
| 上述 20 次请求加停止后的实际写盘次数 | 未测 | 2 次 |
| 地图静止帧（含呈现等待） | 18.04 ms | 17.32 ms |
| 鼠标悬停帧（含呈现等待） | 18.13 ms | 17.20 ms |

提交平均值包含一次快照复制，其余行走请求被节流合并；不能理解为每次独立快照都只需 0.037 ms。保存本身的耗时仍然存在，改善在于不再逐步阻塞绘制。帧测量包含 SDL 软件呈现／同步等待，不能据此换算 Mac GPU 的实际 FPS。ASan/UBSan 构建用于查错，不用于性能比较。

## 已完成验证

- 普通优化、通用发布、ASan/UBSan 三种构建均通过 11 组 CTest：包括 321 项核心规则、7 项后台保存、185136 项地面层及兼容检查、15 张下载地图的 169 项导入检查。
- 三种构建的英雄窗口、冒险地图、行走截图逐字节相同。报告位置八方向共 64 帧均可见，最少有 654 个英雄／旗帜差异像素；树木前景遮挡回归检查继续通过。
- 640×480、1512×982、2388×1668 三种尺寸验证原按钮位置可点击、旧按钮多出的下方区域不可点击、Enter／Esc 可返回。
- 普通构建交互回归生成 160 张图，扩展显示回归生成 190 张图，覆盖寻路、野兵触发、施法、战斗结算、地图手势、动画与练习地图胜利流程。
- Mac Retina 全屏使用报告进度的私有副本，实际点击确认按钮返回，按原路向北两格再向南两格，英雄和旗帜持续可见。退出后副本在 `(9,42)`，行动力按四步减少 400，其余资源、部队、经验和魔法值保持不变。
- 原始用户进度的 SHA-256 在任务前后相同。更新不会替换它。
- 发布应用校验 11404 个内置资源文件、严格签名与独立资源发现；支持 Apple Silicon／Intel，最低 macOS 14，保持默认全屏。

本次完整胜利回归使用练习地图，并未重玩 Wayfarer 全部剧情。此版本不表示全部原版功能和画面已经一致。结构化结果见 `data/native/validation-0.48.json`，日志及截图见 `references/validation/0.48/`。
