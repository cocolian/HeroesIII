# 0.32 探索地图访问光标

宝箱、宝物、资源、矿场、神殿、魔法泉、方尖碑、贸易站、风车和水车悬停时，显示原版扬蹄马访问光标。未知或不可达物品、普通地面、侧栏和其他界面不会显示该访问提示；离开物品、切换界面、窗口失焦或关闭时恢复系统光标，避免双光标及光标消失。

采用校验过的原版 `CRADVNTR.def` 第 9 帧，原始名 `CursrA24.pcx`。完整画布 40×40，实际裁剪 28×31，点击热点取 `(16,16)`。使用原始像素在 Retina 画布绘制，不经过高清重绘或边缘增强，也不随地图缩放改变光标大小。来源及 43 帧原始图像索引见 [source.json](../references/cursor-review-0.32/source.json)。

悬停和点击共用对象命中逻辑，透明边距与阴影不算主体；动画各帧主体取并集，使风车叶片旋转时提示保持稳定。点击主体会寻路到对象访问格，现有直接地块访问仍保留。英雄已站在风车等物品上时可点击再次访问，重复领取限制不变。拖动过程中暂不显示访问光标，拖动结束后正常恢复。

验证覆盖演示图全部 19 个非战斗事件物品，共 10 类，以及 65%、100%、180% 地图缩放。包含物品主体命中、访问格寻路、宝箱拾取、原地重复访问、迷雾/不可达限制、场景切换和失焦恢复；悬停不改变游戏 JSON 或随机数。开发/发行/ASan/UBSan 核心、格式和音频检查分别为 288 / 14 / 22；发行完整流程 314 张 PNG，开发与 sanitizer 重点流程各 87 张。两张图鉴的选中兵种在完整/重点流程中不同，不作全部 PNG 相同声明。

固定练习图仍在第 18 天完成，62 次移动、四场战斗、四次施法、2150 经验。Mac 实际窗口观察到水晶矿上的马形访问光标；本轮未由代理在实机重新执行整张地图，完整流程由自动操作验证。证据见 [validation-0.32.json](../data/native/validation-0.32.json) 和 [验证截图目录](../references/validation/0.32/)。Mac 包仍为临时签名、未公证开发版，iPad 工作继续暂缓。

本轮只完成物品访问光标及相应命中。城镇、战斗、移动天数等完整光标状态，以及全部原版热点偏移尚未逐项校准；项目整体仍未完全复刻原版。
