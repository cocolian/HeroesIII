# 0.36 统一玩家旗帜颜色

我方英雄、地图城镇、已占领矿场和小地图归属标记统一为蓝色；敌方红色、中立灰色。占领矿场后立即切换颜色，同一城镇素材可同时服务不同归属的对象。

原问题有两部分：英雄单独固定使用蓝旗，而地图对象没有接入所属玩家的颜色；城镇/矿场原始 DEF 的归属标记索引 5 在通用透明处理后不可见。另外，本项目的 `owner=0` 表示我方，原版调色板的颜色 0 却代表红色。现在显式映射我方到原版蓝色 1、敌方到原版红色 0，避免混淆两种编号。

离线生成器从已核验试玩数据中读取城镇、矿场和玩家调色板，输出带归属颜色的图集。地图只替换索引 5 的颜色及透明度；地图最后 32 个索引含有普通石材、木材颜色，不能当成玩家色整段替换。战场旗帜则按 `PLAYERS.PAL` 替换最后 32 色。英雄使用原始 AF01 蓝旗，保留其明暗与动画；我方战场蓝旗的生成文件与原文件逐字节相同。运行时按所属玩家选择独立缓存文件，避免占领后沿用旧颜色。

[来源](../references/ownership-0.36/source.json)记录逐个 DEF 和调色板的校验；[派生检查](../references/ownership-0.36/verification.json)验证 54 张图集的索引图像数据相同，48 张地图图集只改变归属标记的颜色与透明度。具体地图标记通过原始索引和可见形状识别；不声称已逐像素校准原版运行程序的全部颜色表现。

自动检查覆盖九种城镇、七类矿场、同素材不同归属、中立矿场占领后的缓存刷新、小地图颜色、65%/100%/180% 缩放及经典/高清模式。直接读取渲染像素验证旗帜颜色；渲染和缩放不改变游戏状态或随机数。英雄、小地图和战斗旗帜均从同一玩家颜色映射取值。

开发和 ASan/UBSan 重点界面各 114 张，发行完整流程 341 张；核心 290 项、格式 14 项和音频 22 项在三组均通过。112/114 张共享 PNG 相同，两张图鉴因完整/重点流程选中内容不同而不同，十份共享审计一致。固定练习图仍在第 18 天完成，62 次移动、4 场战斗、4 次施法、2150 经验。规则及存档格式未改变，本轮没有新增真机鼠标通关、Intel 或 iPad 验证。
