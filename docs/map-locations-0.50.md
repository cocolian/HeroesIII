# 0.50 地图地点规则与验证范围

本次将 0.49 审计中剩余的 41 类物件接入访问规则。保留地图坐标、原始阻挡数据和原版动画，提供中文操作、数量、价格、确认与取消。消费、献祭和守卫战斗需要明确选择；普通拾取与揭图直接结算。此处的“接入”指下列功能可用，不代表完整游戏或所有界面已经逐像素复原。

| 类别 | 原始类型 | 行为 |
| --- | --- | --- |
| 生物巢穴 | 17、20、216、217、218 | 80 种普通及两种特殊巢穴配置；随机巢穴遵守关联城镇、允许阵营与等级；高阶巢穴守卫、占领、招募和每周刷新；一级生物免费，其他生物按七资源价格付费；已占巢穴增加匹配城镇周增长 |
| 难民营 | 78 | 每周重新选择生物并重置兵源，按价格招募，不能占旗 |
| 生物宝屋 | 16、24、25、63、84、85 | 七种宝屋以及废弃船只、龙之国、金字塔、墓穴和沉船；固定随机档次、守卫、战利品、原版包围布阵；胜利后一次性奖励，部队栏满时保留奖励；金字塔要求魔法书和高级智慧术 |

| 地图情报与保护 | 13、15、27、37、58、60、80 | 制图师按玩家／地图种类收费一次；黑暗天幕保留盟友及敌方英雄／城镇的即时视野；同色魔眼与小屋跨层联动；观测地点揭开半径 20 地图；避难所阻止敌方英雄攻击 |

| 原版未启用物件 | 50 | 时空市场在死亡阴影中没有交易服务，明确显示原版状态，不添加其他版本的遗忘技能服务 |

巢穴存量按周重置，不累积未买兵源；高阶守卫周刷新，己方可以直接招募；元素汇集点包含五级土元素，因此周刷新时补齐四系元素守卫。已攻克的空墓穴、船只与金字塔处理再次搜索的士气／幸运惩罚。宝屋随机档次、宝物和生物奖励在访问前固定并保存，重新打开窗口不会重新抽取。

战争机器使用原始属性、动画和部署行。弩车可以造成伤害，炮术影响倍伤概率与高级别双射；存活的弹药车使同侧射手不消耗弹药；帐篷按急救熟练度治疗最上层受伤单位，不复活。机器不能移动、不能复活，不计入英雄带出战场的七格军队，也不能单独维持胜利。机器损毁后移除对应装备；宝屋战斗不带机器，守城方不部署弩车。

新增技能数据扩为 28 项，存档格式升到 16，自动扩展旧版英雄与守方技能数组。接入寻路、侦察、航海、理财、学习能力、魔力、抵抗力、炮术与急救效果。外交、弹道、鹰眼、招魂、学术、战术的完整效果仍是全局系统缺口；地点可以传授、升级和保存这些技能，本次不把“教学成功”描述为这些系统已经完整实现。原版职业概率、所有物件专用窗口、招募英雄的精确开局随机军队、随机巢穴外观替换等仍需进一步对照。

## 验证方式

- `native_locations` 对全部 41 类分派和关键边界执行 343 项检查，包含实际守卫战斗、一次性奖励、满栏恢复领取、资源不足的原子性、每英雄限制、跨层视野、阵营限制、机器伤害／补给／治疗／损毁、召唤共存、敌方机器战后结算及中途存读档。
- 开发、arm64／x86_64 通用发布、ASan／UBSan 构建各运行 13 组 CTest。
- 图形测试在个人进度副本上创建受控地点，依次点击全部 41 类窗口、执行可用操作、结束守卫战斗并返回地图。使用原始地图的物件图形，另检查工厂三种机器的战场显示。三种构建各输出 106 张一致的截图，覆盖分页、最大数量、支付确认与返回。这是隔离规则的界面测试，不是 41 类都在原地图中正常步行到达的通关证明。
- 15 张下载地图重新审计，当前 72 类 Site 的通用未实现分支为 0。原先类型 221 在新导入地图中归为 TradingPost，因此 Site 类别数比 0.49 少一类。该审计只能证明分派覆盖，不能证明原版规则完全一致。
- Dead and Buried 的完整流程由正常经营、行军、战斗自动驱动，未注入兵力、资源、传送或额外揭图。最终零读档第 84 天胜利；视频为 19 天，仍有明显差距，不能当作原版电脑强度或视频打法的等价比较。完整运行记录见本机验证文件。
- Seven Lakes 自动流程暴露并修正了运兵英雄向满编、不兼容军队反复靠近的问题；测试驱动也修正了战败位置和危险阈值记录。本机保留失败尝试，最终仍在敌军进攻阶段耗尽自动重试预算，未通过此图通关测试，不能将其列为本版本已通关地图。
- 原个人进度只读取、复制，校验 SHA-256 后保持不变。界面、完整流程及安装包记录保存在本机 `data/native/validation-0.50.json` 和 `references/validation/0.50/`，不提交个人存档。

```sh
cmake --build build/native
ctest --test-dir build/native --output-on-failure
build/native/h3_map_object_audit data/native/map-site-audit-0.50.json
build/native/HeroesIII.app/Contents/MacOS/HeroesIII \
  --location-tests /tmp/heroesiii-location-ui \
  --campaign-save /path/to/private-save-copy.json
```
