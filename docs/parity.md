# 原版一致性验收清单

目标版本：经典《英雄无敌 III Complete / 死亡阴影》，含末日之刃九阵营，不混入 HotA 的数值和内容。当前实现：C++20 / SDL2，0.38.0，Mac 输入使用 Objective-C++ 桥接。**总体状态：开发中，未达到原版功能或画面完全一致。** 用户另选定“按原版构图重新绘制 2K 美术”；高清重绘模式按该方向推进，经典模式继续保留原版素材。

本清单中的“接入”只代表代码中已有该部分。规则回归测试验证已知行为和状态一致性，离屏截图验证界面可渲染；这些都不能代替与原版逐条规则、逐像素和逐帧对照。未经原版对照的系统不标记为完全一致。

本轮的全屏视口、21 个 Scene 对照和整张演示地图流程见 [0.26 逐屏/通关记录](fullscreen-review-0.26.md)。新增窗口面积用于显示更多地块，F4/F11/Cmd+F 切换全屏。魔法行会和战报恢复原版框架；结果视频及多处临时窗口仍缺。0.26 归档记录为锁屏时的自动检查；解锁后的真实全屏和连续鼠标通关补验见 [0.27 实机记录](live-review-0.27.md)。
