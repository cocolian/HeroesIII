# 0.39 按钮说明、寻路与野兵守卫

鼠标停留约 0.45 秒显示按钮说明；按住右键立即查看，松开关闭。原版图形按钮保留原来的图像与尺寸。说明包括用途、已支持的快捷键，以及灰色控件的限制。建设确认明确列出建筑和费用，法术说明列出魔法消耗、魔法值不足和本轮已经施法等状态。

覆盖主菜单、冒险地图、英雄、城镇、大厅、建设确认、堡垒、招募、部队交换、拆分、魔法行会、大学、魔法书、战斗、战报、升级、市场、选项、帮助、图鉴及场景选择，共 21 类界面。尚未实现的功能会明确标记。右键取消已选法术的原有操作仍然优先。

寻路以总行动力为首要费用，相同时优先较少步数，保持确定结果，不消耗游戏随机数。地图当前使用土路图像，因此相邻两个格子都是道路才按 75% 计费。进入或离开道路按目的地地形计算；普通地形直行 100、斜行 141，土路 75 / 106，沙地 150 / 212。地形规则仍只覆盖本演示地图支持的地形和技能范围。

野兵控制本格及周围八格，陆地与水面分开。寻路避开其他可见守卫的控制区；通道被封锁时需要明确攻击守军。点击野兵会选择可达的接近格；直接攻击相邻野兵时，英雄留在原格进入战斗。重叠守卫按固定的列优先顺序选择，一步只触发一场战斗。未探索的野兵不会泄漏到路线计算中；实际移动揭示野兵后仍会正常拦截。

守卫控制的宝箱、资源、宝物和矿山先触发战斗，胜利后才结算访问。战败不会发放物品，仍有另一支守军时也不能直接拿走。战斗中和战报确认前不能继续移动或访问物品。战斗开始会清除行军状态与路线，修复直接攻击相邻野兵时停留在冒险界面的问题。
