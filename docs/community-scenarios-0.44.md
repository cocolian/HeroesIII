# 社区地图原图探索 · 0.44

此前下载的地图只接入了地形缩略图，地图启动按钮被禁用。0.44 增加原始 H3M 转换和原生地图加载，14 个文件均开放“原图探索”。

进入 **新游戏 → 左下角“选择地图 · 已下载地图” → 选中地图 → 选择此地图 → 开始原图探索**。练习图仍可独立选择。更新后需要启动新地图；已有练习图进度不会自动变成其他地图。

载入的是原始 144×144 地图及其地上/地下层，保留地形帧与翻转、道路与河流、物件坐标、访问格和阻挡、原始起始英雄与军队。支持部分地图事件与任务守卫、通道、登船/下船、拾取、矿场每日产出、多城镇收入、原有战斗与施法、部分胜利目标；攻下第一座城不会自动把整张大地图判胜。长篇事件可翻页阅读，确认后继续。

支持的是开发中的探索模式，**不代表 14 张地图都已具备原版完整通关条件**。电脑在地图上的行动、多英雄控制、完整英雄职业与宝物系统、全部物件/剧情规则仍缺。未实现的访问规则会显示提示并保留物件；只有首个人类势力可控制，其余势力暂归为敌方。未预设的随机部队与城镇采用当前引擎的生成逻辑。Seven Lakes 原图没有预设英雄，当前会自动花费 2500 金币招募一名起始英雄；不等同于完整酒馆开局。

离线转换工具、来源、哈希与 Clang 修正见 [转换记录](../references/h3m-import-0.44/README.md)。游戏内置原始 H3M 和转换数据，不需要安装转换器。

测试证据记录在 `data/native/validation-0.44.json` 及 `references/validation/0.44/`。地图测试覆盖全部文件的真实开局、初始探索一步、维度与层数、部分存档往返、地下通道和任务守卫；另用明确控制部队/位置的夹具检查原图矿场次日产出、施法扣血、战斗后占城、多城收入及胜利判断。这些夹具不作为自然通关证据，14 张社区地图尚未逐张通关。
