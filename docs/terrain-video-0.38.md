# 0.38 地形接边、实况核对与扩充地图

本轮继续修正地图块边缘。旧的像素材料估计把部分内角选成了另一组曲线，也会选错翻转方向。现在从六组已收集的 SoD 地图读取原始地形 view ID 和 XY 标志，按邻域校准原版 DEF 选择，校正 232 个邻域的几何选择；没有重绘、模糊或透明混合地块。7073 种组合仍均有有效原版帧，未观察到的组合保留旧的像素匹配后备。

只读 H3M 解码器在边界检查后解析头部和七字节地形记录，不加载下载的程序，不解释地图对象/事件，也没有把当前固定 36×28 练习图改成完整 H3M 场景。格式参考为 [h3mtxt 作者的 H3M 规范](https://github.com/alexanderbelous/h3mtxt/blob/master/doc/h3m_specification.MD)，本地文档和来源散列保存在 `references/map-review-0.38/`。

用另外四组地图检验，未纳入校准集：Seven Lakes、The Lone Knight、Jennifer's Dream Journey、Jedi Story。13634 个符合范围的过渡格中，首选贴图的几何组及有效翻转方向与地图记录相符的数量由 10070（73.9%）提高到 13035（95.6%）。此指标只覆盖草/泥/沙/水邻域的内部过渡格，合并同形纹理变体；不是整幅画面像素相似度，也不代表全地图完全一致。约 4.4% 的局部角型还需要比八邻域更完整的上下文。原始 view ID 的完整场景运行时导入仍未完成。

![左：0.37；中：0.38；右：地图保存的原始 view ID](../references/map-review-0.38/terrain-before-after-original.png)

原生渲染回归新增六个来自未参与校准的 Seven Lakes 的凹凸角案例，每个检查 32 个纹理选择值，并继续覆盖 65%/100%/180% 地图缩放、道路河流覆盖、游戏状态及 RNG 不变。独立 H3M 检查覆盖未压缩/GZIP、条件字段、截断、超长计数、无效图块和全部下载地图。

本轮新增两段各四分钟的[重剑阿修斯《死亡阴影》战役实况](https://www.bilibili.com/video/BV16K4y1x7Gj/)核对，整理地图道路/迷雾/对象遮挡、还童泉访问、随后的狼骑兵战斗、障碍及魔法书。该视频含 HD 界面，不作为纯原版尺寸证明；另一入门教学的预览主要是浏览器文档，未作为游戏画面对照。逐帧图与筛除记录见[视频画廊](../references/video-review-0.38/index.html)。还童泉弹窗没有被误记成野怪交互窗，这些片段也不足以确证守卫警戒半径。

流程核对修复了一个规则接口漏洞：战报未确认时仍可移动英雄并拾取资源。现在先确认战报；新增核心回归，并在四场自然战斗后的完整练习图通关流程逐次验证。战场池塘/岩石的真实阻挡、守卫警戒范围、野怪加入或逃跑仍是缺口，本轮未宣称补齐。

新增四组公开社区地图，共六个 H3M：The Lone Knight（14 Likes）、Seven Lakes / Oscar Sedell 版本（6 Likes、普通难度）、Jennifer's Dream Journey 中文版（26 Likes）及 Jedi Story（25 Likes、三版本）。累计十组十四个 H3M，原始 ZIP/RAR、站点记录、校验和和地形区块校验均保留。Likes 是公开点赞数，未作星级或已通关保证；同名 Seven Lakes 没有混入 HotA 版本。见[地图目录](../maps/community/README.md)。

验证与安装包记录见 `data/native/validation-0.38.json`，完整离屏画面及检查日志见 `references/validation/0.38/`。本轮离屏自动流程不等于在真实 Mac 窗口手动通关；iPad 真机签名与安装仍按用户要求暂缓。
