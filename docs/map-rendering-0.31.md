# 0.31 地图素材核验与渲染修正

本轮重点是经典 Complete / 死亡阴影的冒险地图。**原始素材已用于更多地图对象，但尚未达到与原版同地图逐像素、逐帧一致。** 高清重绘模式仍保留，F7 可切换经典素材。

## 先辨认图片，再采用

新下载并逐张查看了 15 张候选截图，另下载一份原版教程 PDF：

| 来源 | 识别结果 | 本轮用途 |
|---|---|---|
| [Game Over 1999 年评测](https://www.game-over.net/review/mar99/homm3/)的 7 张 800×600 JPEG | 2 张冒险地图；其余为原版菜单、英雄、城镇、魔法书和战斗 | 两张地图作为高置信的经典外观参考，其余分开存放 |
| [原版 RoE 教程镜像](https://draketungsten.org/arcade/pcmanuals/HoMM3_-_tutorial.pdf)，12 页 | 原版教程文档，第 1 页包含冒险地图；文档中的图片经过印刷排版/缩放 | 作为第三个地图视图参考，保留整页与 PDF，不冒充原始像素截图 |
| [Steam 1999 原版商品页](https://store.steampowered.com/app/4921760/)的 8 张 1920×1080 图片 | 来自官方商品页，但有模糊侧边背景、缩放和宣传排版 | 全部排除原始截图尺寸/像素基准，保留排除理由 |

因此本次新增的是 **2 张评测地图截图和 1 个教程地图视图**，不是 15 张新地图。地图图库另外链接上轮已有参考，不把重复图片算成新增。未下载成功或版本未核验的现代文章图没有进入基准。

判断依据包括原始评测时间与上下文、完整 800×600 经典界面、32 像素地块、原始精灵轮廓，以及是否存在 HotA/WoG、新版 HD 重绘、裁切或宣传处理。两张评测图的准确补丁号尚未独立确定，JPEG 压缩也不能证明逐像素身份；“高置信经典截图”与“像素基准”分开记录。

[本轮图库及前后对照](../references/map-review-0.31/index.html)、[逐图分类与 SHA256](../references/map-review-0.31/sources.json)、[原版格式参考](../references/map-review-0.31/format-reference/sources.json)均保留在项目中。格式资料固定 VCMI 提交 `e3936f8bb76467e7feef4346927d208e07ee2467`，仅核对画布锚点、调色板范围和格式事实，没有导入其引擎实现或连接查表。

## 地图修改

不再从网上截图裁出运行精灵。运行素材来自已校验的 Mac Complete / Windows RoE 公开试玩资源，保留逐项归档散列。

- 生成 `assets/demo/adventure.json`：1305 个原始对象模板、141 种野怪的地图精灵映射，以及访问格偏移。使用原版 DEF 完整画布和裁剪偏移，统一按 32 像素地块与地图缩放比例绘制。
- 树木、山体、矿场、城镇、泉、方尖碑、神殿和贸易站改用原始 DEF。演示地图的单格山体表示选用紧凑的原版山体，不再把大山图压成两格。金矿、水晶矿等各用对应素材。
- 宝箱改用 `AVTCHST0` 八帧；七资源使用对应 `AVT*` 地图精灵，宝物保留原始 `AVA0008` 的 64×32 画布。野怪由头像换成原始 `AVW*` 地图动画。
- 英雄、地形装饰和对象共同按地图行/列排序，修正“英雄永远画在所有物体上方”。这是本项目的深度排序；原版全部多格对象的分块穿插、悬浮优先级仍未完整校准。
- 风车使用原始 160×96、八帧 `AVMWNDD0`；水车使用 96×96、八帧 `AVMWWHL0`。练习图加入两种可访问对象及每周领取状态，旧有对象 ID 不变。
- 水面和清水河使用原始索引调色板循环，180ms 一步。水面循环范围 229—240、242—253；清水河为 183—194、195—200。生成十二阶段调色板图片，不移动、拉伸地形贴图来模拟水流。
- 土路改用原始 `DIRTRD`，清水河使用 `CLRRVR`，增加原始海岸边缘帧。道路/河流连接通过本项目对原始透明轮廓采样选择，海岸使用局部邻格选择；完整地图编辑器的全部连接规则仍未实现。

渲染时钟、对象排序及调色板选择不消耗游戏随机数。旧地图记录没有 `river` 字段时按无河流读取；本轮没有改写用户的实际存档。

## 验证

- 开发、发行、ASan/UBSan 三组均通过 **288 项核心、14 项资源格式、22 项音频检查**。
- 发行版完整流程生成 **306 张 PNG**；开发及 ASan/UBSan 重点流程各 **79 张**。共享的 79 张中有 77 张散列一致，两张图鉴页因完整流程先前选中了不同兵种而不同；六份相同场景审计均一致。
- 新增八张地图专项图。65%、100%、180% 缩放检查原画布比例和访问格；风车在 1440ms 回到八帧循环起点，水面在 2160ms 回到十二阶段起点。动画播放不会改变游戏 JSON / RNG。
- 遮挡测试确实覆盖了英雄身体的 **99 个像素**：原始树木的不透明区域必须遮住身后英雄。反转对象容器顺序后地图像素不变，避免绘制依赖对象插入顺序。
- 固定 36×28 练习图仍在第 18 天通关：62 次移动、四场战斗、四次施法、2150 经验、两次技能选择。没有为通关注入资源或军队。
- Mac 实际窗口从独立新局进入经典全屏，拾取宝箱后金币 **10000→11500**，访问风车后水晶 **5→8**；再次访问没有重复领取。英雄到达 `(9,23)`，风车保持原始帧动画，留存三张截图和独立输入/状态记录。本轮未实机走到水车或宝物，它们由离屏场景和自动练习图流程覆盖。
- Mac universal 包包含 **11142 个核验运行资源**，严格临时签名有效，仅依赖系统动态库，禁用项目目录后备，最终 DMG 完整性通过。最低 macOS 14；本轮没有重测 Intel 运行或 iPad，后者按用户指示暂缓。

完整证据：[validation-0.31.json](../data/native/validation-0.31.json)，[截图与日志目录](../references/validation/0.31/)。安装包为临时签名、未公证的开发测试版。

## 仍有差距

演示地图布局不是原版场景，尚无同地图、同视口、同时刻的原版可执行程序对照。全部地形过渡、河口/桥梁、对象占用与点击范围、城镇/矿场归属旗帜、原版影子混合和动画节奏仍需校准；当前行排序也不涵盖所有多格分块遮挡。原生 H3M、地下层、完整对象库、多英雄与完整宝物装备系统仍未完成。网上静态截图不能证明水流方向与全部动画时序相同，当前循环范围及步长依据格式资料，尚未逐帧对照原版录像。
