# 0.29 · 路线箭头与英雄比例

按用户提供的原版截图，地图路线已从方点改用公开演示版提取的 `ADAG.def`：直行箭头、随前后路径转弯的箭头、终点叉标；当天可达为原素材绿色，后续路段为原素材红色。箭头按地图格绘制，跟随地图缩放。

英雄不再裁剪通用图集的小块缩略图，改用 `AH00_.def` 的 96×64 原版骑马画布，在 32×32 地图格上按原版脚下位置对齐，叠加蓝方 `AF01.def` 旗帜。人物、马匹与旗帜同步缩放；移动后保留朝向，向西使用相应镜像，并使用素材中的行走与旗帜帧。

原生开发版与最终通用发行版均完成 50 张重点渲染检查，包括 65%、100%、180% 地图缩放、可达/后续路线、扩展全屏、触控以及整张练习图通关。练习图第 18 天结束，62 步移动、4 场战斗、4 次施法。发行版另通过 284 核心检查、14 资源格式检查和 22 音频检查。

在 Mac 全屏实际窗口完成新局、规划宝箱路线、行军、拾取 1500 金币及返程。绿色直行/转弯箭头、英雄大小、返程朝向及路线消失均已观察；金币保持 11500，测试数据隔离于 `/private/tmp/heroesiii-0.29-live`。

通用发行包包含 arm64 与 x86_64，最低 macOS 14，内置 11,117 个已校验运行文件，严格签名和仅系统动态库检查通过。使用本地临时签名，尚无 Developer ID / Apple 公证。0.29 本轮未重复 Intel Rosetta、ASan/UBSan 或 iPad 验证；这些平台此前的记录仅对应其原版本。完整原版功能与画面一致性仍未完成。

更新文件位于 `dist/HeroesIII-0.29.0-macOS-universal.pkg` 和同版本 DMG。原截图、当前截图、检查日志与散列记录位于 `references/validation/0.29/`，旧版本安装包与验证归档保持原样。

原素材来源由 `assets/demo/manifest.json` 与 `references/demo/source.json` 追溯。方向与可达性语义交叉核对了 [VCMI 的地图路线渲染实现](https://github.com/vcmi/vcmi/blob/develop/client/mapView/MapRenderer.cpp)；本项目按相邻格的入向、出向叉积选择素材帧。
