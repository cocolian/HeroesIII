# 0.37 菜单、地形接边与矿山产出

用户指出主菜单仍为自制红色矩形、地形之间呈直角硬切、矿石矿占领后库存看起来不增长。本轮恢复原版图形按钮和陆地过渡帧，实测矿山自动产出，并补充了产出提示。当前仍未达到完整原版功能和像素一致。

## 矿山

检查前的代码已有按所有权发放每日矿山收入的逻辑。当前源代码未复现普通矿山不增长，因此本轮不把它归因为已确认的算法漏结算。新增的连续流程从地图实际走到矿石矿、占领、离开，再通过原位置的结束回合按钮和 E 键推进三天；矿石应为 20→22→24→26，800×600 与 1512×982 的资源栏均校验数字区域变化。

矿石、木材各为每日 2；水银、硫磺、水晶、宝石各为每日 1；金矿为每日 1000 金币。结算入口统一使用当前己方所有矿山的产出，按座数叠加，城镇仓库另计，库存遵守现有十亿上限。失去矿山后停止产出；占领当日和重复访问不会额外领取。占领、重访、悬停及次日状态文字给出明确数量与入库时点。

发现并修复了战报尚未确认时，规则接口仍可推进日期的问题。战斗、战报、升级选择或地图结束时不结算新一天。新增三个核心回归覆盖矿石矿连续产出/失去所有权、七类矿山及多矿与资源仓库叠加、未关闭战报和库存上限。

完整回归还发现新矿山测试的时钟隔离遗漏：前面的流程已经推进模拟时间，而新测试将时间重置，等待旧行军截止时间。已修正测试的时钟衔接。这是自动测试夹具问题，未把它记为实机游戏故障。

## 菜单

使用已校验 Mac Complete 试玩数据中的五组 DEF：`MMENUNG`、`MMENULG`、`MMENUHS`、`MMENUCR`、`MMENUQT`，保留各自画布尺寸，恢复正常、悬停、按下状态和图形轮廓命中。入口恢复新游戏、载入、最高得分、制作组、退出；图鉴保留 I 快捷键，本局继续使用 Esc。

目前使用原试玩包的英文按钮。收集到的中文社区替代按钮与原始图形不一致，未作为原版按钮接入。背景沿用 0.35 的社区保存 SoD 构图，其来源和限制不变。新游戏仍是练习图阵营选择，载入仍是当前手动档；最高得分仅展示本局练习通关成绩，未实现原版持久排行榜/评分公式；制作组不是原版完整片尾动画。

## 地形

此前陆地一直选择内部纹理帧，完全没有按相邻地形选择边缘，因此草地与沙地出现方形硬切。现接入 GRASSTL 的泥地/沙地/混合边缘、DIRTTL 沙地边缘、WATRTL 沙岸及内外角，使用八邻域和镜像选择原始 DEF 帧；沙地保留原始内部纹理。道路、河流和对象仍在地形之上绘制，迷雾仍最后覆盖，不通过模糊、人工渐变或重绘替代原始地块。

`scripts/generate-terrain-art.py` 从校验通过的原始 DEF 像素独立生成 7073 种邻域组合；帧编号/边缘材料参考 VCMI 公开格式数据，未导入其引擎代码。运行时索引为 `assets/demo/terrain.json`，帧与来源校验记录见 `references/terrain-0.37/source.json`。校验覆盖直边、凹凸角、草/泥/沙/水组合、道路河流及 65%/100%/180% 缩放。

当前是针对生成练习地图的邻域选择器；没有读取原始 H3M 保存的地块 view ID/翻转标志，也没有宣称任意原版地图逐像素一致。单格细条、复杂三种地形接点等原地图编辑器不规则局面仍需更多原版对照。
