# 英雄无敌 III · C++ 原生实现

项目主实现已改为 **C++20 + SDL2**，当前 0.51.0，可编译成 macOS 桌面 `.app`；Mac 鼠标事件使用一小段 Objective-C++ 桥接。冒险地图按窗口扩展视野；城镇/战斗/弹窗保留原版 4:3 构图，支持 Retina 物理像素、经典素材与首批高清重绘切换。当前是支持多英雄、九阵营建设与招募及基础电脑回合的可玩开发版本，**没有达到完整原版的功能或画面一致性**。

本 GitHub 仓库提交源码、生成的 C++ 规则数据、构建／采集脚本、测试和文档。运行素材、下载地图、参考资料、截图、安装包及个人存档保留在本机，不包含在 Git 中。首次克隆请先阅读[源码仓库与构建说明](docs/source-repository.md)；下文的素材与安装包链接指本地完整开发目录。

## 直接启动

本机已经构建：

```
build/native/HeroesIII.app
```

双击 `启动英雄无敌.command`，或运行：

```sh
./scripts/run-native.sh
```

上述开发版需要保留本项目的 `assets/` 与 `references/` 素材目录。开发版与发行版均使用固定源码版本的静态 SDL2 依赖；`dist/` 中的通用 Mac 安装包还内置全部运行素材，可独立运行。

## 构建与测试

需要 Xcode Command Line Tools 或完整 Xcode，以及 CMake；脚本从固定版本源码构建图形、字体和 JSON 依赖：

```sh
brew install cmake
./scripts/build-native.sh
```

也可以直接使用 CMake：

```sh
cmake -S . -B build/native -DH3_VENDOR_DEPENDENCIES=ON -DCMAKE_BUILD_TYPE=Debug
cmake --build build/native -j 4
ctest --test-dir build/native --output-on-failure
```

只编译规则核心，无需 SDL：

```sh
cmake -S . -B build/core -DH3_BUILD_GUI=OFF -DCMAKE_PREFIX_PATH=/opt/homebrew
cmake --build build/core
ctest --test-dir build/core --output-on-failure
```

原生渲染检查：

```sh
SDL_VIDEODRIVER=dummy build/native/HeroesIII.app/Contents/MacOS/HeroesIII --render-tests native/screenshots
```

实机开发检查可添加 `--save-dir /tmp/heroesiii-live-check`，将游戏和客户端设置隔离；`--input-trace /tmp/heroesiii-input.jsonl` 可记录鼠标事件的位置、修饰键、窗口和物理输出尺寸，默认关闭。

## 操作

- 主菜单回车进入阵营选择，选好阵营后激活“开始游戏”；Tab / 上下方向键切换按钮，回车激活，Shift+Tab 反向切换。
- 地图点击规划路径，再次点击或 M 行军；双指滑动或滚轮移动地图；按住触摸板上下拖动缩放（上移放大、下移缩小）。iPad 单指拖动平移、双指捏合缩放。
- H 英雄、T 城镇、C 魔法书、B 市场、E 结束回合、空格居中/重访、Esc 返回。
- S 保存，L 优先读取手动档，Shift+L 读取自动档；战斗进行中也可保存和继续。
- F7 切换高清重绘/经典像素，F4 / F11 或 Cmd+F 切换全屏；Cmd+Q 退出。
- O 打开系统选项，F10 静音。音乐与音效各十档，可点击或拖动原版音量条；左右键、Home/End 调音乐，按住 Shift 调音效。英雄速度、地图滚动、路径显示和城镇描边可设置。字母键及静音键是辅助操作。
- 资源市场可远程使用；选择交出/换取的资源，拖动滑块或用左右键、Home/End 调数量，点击握手确认。贸易站须英雄实际访问，固定使用五市场价格。B 为便捷打开键。
- 当前骑士开局没有魔法书。建好行会后入城，花费 500 金币购买；智慧术允许学习更高等级法术。
- 城镇中点击建筑、堡垒/大厅小图标或周增长兵种头像进入服务；H 打开大厅、R 打开堡垒、A 打开辅助军队管理。
- 招募中左右键、Home/End 调数量，回车购买、Esc 取消；G 切换英雄/驻军，U 切换已建高级兵营的基础/升级兵种。这些字母键为补充操作。英雄必须实际入城才能接收部队和交换驻军。
- 城镇军队栏可拖放或依次点击来源、目标，移动/合并/交换；Shift 拖到或点击目标可拆分。驻军内部可远程整理，跨英雄/驻军须入城；英雄不能交出最后一个单位。选中同一部队再次点击可进入辅助管理及升级。
- 战斗中点击空格移动，点击敌军攻击；D 防御，W 等待，C 选择法术。
- 英雄界面右下原版按钮切换松散/紧密阵型。战斗中 F6 切换网格，底栏双剑开启基本自动战斗，Esc 或再次点双剑停止；自动 AI 的完整法术和特殊能力决策仍缺。

实机已验证地图平移、点击路线并行军一格、英雄与驻军往返拖放、28 名枪兵拆成 14＋14 再合并，以及滑块招募 14 名并扣除 840 金币。全部操作在独立存档目录中进行；随后正常启动并载入原有自动档，手动/自动存档逐字节保留。

普通和 ASan/UBSan 构建均通过 280 项核心、14 项资源格式、22 项音频检查及 185 张界面，PNG 全部一致。新增场景覆盖宽屏、小窗口、非整数缩放、松开终点结算和 Shift 状态。外接屏、全屏切换及完整输入状态仍待实测；本轮没有新增 2K 美术。原理、实测和限制见 [输入资料](references/input/README.md)。

## 原版士气/幸运特效与群体施法（0.20）

战场改用原版金色/暗色飞鹰、马蹄铁与星光透明帧，替换方形临时图标；正负士气音效分别为 `GOODMRLE` / `BADMRLE`，低士气触发时另播放一次畏缩动作。四个相关法术在成功目标上播放原始特效，群体目标同时开始，施法声音只响一次；免疫/抵抗目标不显示成功动画。底栏显示当前触发或法术名称。

280 项核心、14 项资源格式、22 项音频检查及 178 张界面在普通和 ASan/UBSan 构建通过。每种效果保留全部帧，暂停、输入锁定、群体同步与不改存档均有检查。帧速度暂用 100ms，精确锚点/原版时序、英雄施法和其余法术效果尚未还原；原始分辨率特效不计为新原生 2K 美术。事实对应、源文件与缺口见 [战斗资料](references/battle/README.md)。以下各节保留对应历史版本的状态。

## 士气、幸运与战斗提示（0.19）

英雄窗口显示实际军队士气/幸运，接入幸运术和四个相关法术。高士气可再行动一次，低士气会失去行动；额外行动等待按独立顺序处理。经典幸运按基础伤害加成，伤害结算改用整数比例，避免整数结果因浮点误差少 1 点。格式 10 保留新增状态并兼容格式 1—9。

## 城镇独立建筑重绘与升级替换（0.18）

接入城堡三档城防和两档岗楼的独立透明重绘图，原生密度足以覆盖 2560×1920 输出中的相应区域。位置、逻辑画布、绘制次序和点击蒙版保留原始数据；仅替换单帧静态建筑，不冻结已有动画。低透明度像素的颜色扩展减少缩放彩边，并保持每个像素的 alpha 不变。
